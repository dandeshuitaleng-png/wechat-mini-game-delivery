# Top 50 热门小游戏设计参考库

50 款经过市场验证的热门游戏设计拆解，按 8 个维度（玩法循环/交互形式/界面视觉/角色设计/动效/环境背景/3D 元素/可直接复用）逐款分析。用于立项找基线、设计找参数、美术找配色。

**使用约定**：
- 色值均为目测估计值（标「约」），落地时对目标游戏真机截图取色校准。
- 动效时长、UI 比例为可复用的工程参数，非官方数据。
- 每个分类文件开头的「通用设计公式」是该品类的跨游戏共性提炼，优先读它。
- 用 `grep -n "^## N. 游戏名" references/top-games/*.md` 快速定位单款游戏。
