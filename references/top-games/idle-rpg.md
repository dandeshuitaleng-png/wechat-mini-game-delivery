# 放置 · RPG · 卡牌经营类（10 款）

> 色值为目测估计（标「约」），落地时对真机截图取色校准。

## 通用设计公式

1. **开箱循环骨架**：点核心物（箱/树/灯/锤）→ 爆装 → 新旧对比即穿即卖 → 升级核心物提高品质概率 → 关卡验证。换皮只换核心物和题材。
2. **品质色阶体系**：白→绿→蓝→紫→黄→橙→红→粉/金，7-9 阶，色框+光柱双表现。
3. **分区布局定式**：上半 45-60% 战斗/角色区，下半 40-55% 核心操作+装备区，底部 5 栏导航。
4. **数值爽感三件套**：伤害数字不缩写、爆装光柱按品质分色、批量连开（10 连/100 连）。
5. **挂机经济**：离线收益上限 4-10 小时，上线首屏弹窗一键领取。
6. **单线引导**：同一时间只给一个主线目标，功能入口随进度逐个解锁。
7. **留存钩子组合**：周期活动（21 天）+ 冲榜（积攒-释放）+ 反差副玩法（钓鱼）。

## 1. 咸鱼之王
- **类型/题材**：放置卡牌 + 搞怪咸鱼化三国题材（疯狂游戏/豪腾嘉科）。
- **玩法循环**：点击杀怪→获得咸鱼武将→放置推关→挂机收资源。关卡为数量制（上万关），成长线为等级/升星/鱼灵/装备；付费点为招募令、21 天周期活动礼包。10 连必出红将、红将 8 碎片即可合成，走「易获取、养成上限高」路线；资源可无损转移到新卡。
- **交互形式**：竖屏单指，战斗全自动 + 点击屏幕加额外伤害；新手引导仅 4 步；红点即点即消，功能入口随进度逐个解锁。
- **界面视觉**：主界面上半为战斗区、下半为功能入口，底部 5 栏导航；暖木金黄 UI（约 #F5C063），强调红（约 #D94F3D），Q 版诙谐无紧绷感。
- **角色设计**：咸鱼拟人化三国武将（吕布、太史慈、华佗等），头像框按白→红品级分色，红将金边特效，全英雄约 58 名。
- **动效**：伤害数字不用缩写、纯大数值跳动，强化质变爽感；宝箱支持 10 个/活动期 100 个批量连开，奖励连环掉落。
- **环境/背景**：横版卷轴战斗场景，每 100-300 关换一个主题章节；主城为功能集合页。
- **3D 元素**：无，2D 骨骼动画（类 Spine）小人。
- **可直接复用**：①上 60% 战斗 + 下 40% 功能的分区比例；②伤害数字不缩写；③宝箱批量连开节奏；④21 天周期活动循环消耗囤货；⑤养成资源无损转移降低换卡成本。

## 2. 寻道大千
- **类型/题材**：修仙题材放置 RPG，「开箱子」变体（砍树），三七互娱。
- **玩法循环**：耗仙桃砍仙树爆装备→分解废装升级仙树提高品质→灵兽/精怪/血脉/法宝多维养成→镇妖塔、六道秘境等副本验证。装备 12 部位 9 品质（凡品→至宝），词条随机组连爆/闪避/减伤等流派；付费点为月卡、仙桃与限时礼包。
- **交互形式**：竖屏单指，核心动作就是点树；自动回合制战斗，战前显示敌方妖力供预判；离线挂机持续砍树，上线一键领取。
- **界面视觉**：主界面中央为大仙树 + 角色，底部功能栏层级简洁；水墨国风，米白宣纸底（约 #F5F0E6）、墨青主色（约 #4A7C6F）、描金点缀（约 #C9A254）。
- **角色设计**：开局猪/鸟/鱼三选一小妖，国漫萌系造型；装备品质灰→金红渐变色框；灵兽、精怪、仙友有羁绊立绘。
- **动效**：雷劫渡劫全屏动画、召唤灵兽演出；爆装光柱按品质分色。
- **环境/背景**：云雾山水墨场景，流水带动态感；境界（练气→真仙）解锁新副本与场景。
- **3D 元素**：无，2D 立绘 + 2D 小人战斗。
- **可直接复用**：①屏幕中央单一核心交互物（树/箱/灯）聚焦点击；②9 阶品质色阶体系；③战前战力对比预判；④挂件式多维副养成（羁绊加成）；⑤离线收益首屏弹窗呈现。

## 3. 疯狂骑士团
- **类型/题材**：开宝箱轻度 RPG，西方 Q 版中世纪骑士（磐隆致远研发、疯狂游戏发行）。
- **玩法循环**：开宝箱爆装→穿戴/分解→金币升级宝箱等级提高高品质概率→冒险 PVE/竞技场 PVP 验证→获得更多宝箱。装备 7 品质（普通→神铸）；付费点为宝箱、钻石礼包；钓鱼副玩法显著提升 15 日留存。
- **交互形式**：竖屏，最高频操作是点宝箱，后期开自动开箱解放手指；战斗全自动可跳过；宝石用 5×5 格子镶嵌，需最大化利用空间。
- **界面视觉**：主界面上半为装备栏 + 属性，下半为占据视觉中心的巨大宝箱按钮（下方显示剩余数量）；木质棕 UI（约 #7A4E2D）、石板蓝灰（约 #3D5A99），欧美卡通描边。
- **角色设计**：Q 版骑士，装备穿戴实时换装可见；品质色框白→橙红；翅膀、坐骑、宠物为外挂式展示。
- **动效**：开箱弹跳 + 品质光效，高品质全屏金光；装备新旧属性对比弹窗即穿即卖。
- **环境/背景**：城堡、森林、沙漠等中世纪场景做战斗背景板；试炼之塔按周结算。
- **3D 元素**：无，纯 2D 卡通。
- **可直接复用**：①上半角色 + 下半核心按钮的约 5:5 分屏；②宝箱等级=品质概率表外显给玩家看；③「穿或卖」二选一即时决策；④5×5 空间镶嵌玩法；⑤加一个反差休闲副玩法（钓鱼）拉留存。

## 4. 国王指意
- **类型/题材**：涂鸦塔防 + Roguelike 技能卡牌（又名《正中靶心》/ Doodle Magic）。
- **玩法循环**：怪物分波攻城→击杀攒经验升级→每次升级技能三选一→组火球/闪电链/陨石等流派守住城墙。局外养成为装备 6 部位 + 宝石 7 品级（普通→神话，五合一升阶）+ 城墙/学徒；付费点为宝石、体力、战令。
- **交互形式**：零走位轻操作，唯一点击是升级时的三选一决策；日常关卡支持一键扫荡；单局时长短，适配碎片时间。
- **界面视觉**：极简手绘涂鸦，白底（约 #FFFFFF）+ 黑线稿（约 #1A1A1A），技能用高饱和橙/蓝/紫点缀（约 #FF8C42）；底部关卡/装备/宝石导航。
- **角色设计**：简笔画法师与怪物，不堆立绘，靠技能图标与涂鸦造型辨识；怪物有近战/远程/精英/飞行差异化设计。
- **动效**：手绘风技能特效（奥弹、闪电链、龙卷风），满屏弹幕但画面干净不脏；城墙受击震动反馈。
- **环境/背景**：左侧城墙 + 右侧怪物来袭路径的固定构图；章节换怪物皮肤与限时元素副本。
- **3D 元素**：无，纯 2D。
- **可直接复用**：①局内 Roguelike 三选一决策节奏（约每 30-60 秒一次）；②黑白底 + 高饱和技能色的低成本高辨识方案；③宝石五合一升阶的长线变量；④局外 6 部位装备骨架；⑤日常一键扫荡降重复操作。

## 5. 灵魂序章
- **类型/题材**：斗罗大陆正版 IP 放置 RPG，「打铁」开箱变体，三七互娱。
- **玩法循环**：耗魂力在锻造台打铁→掉落魂环/魂器→替换高战力装备→主线/PVE/PVP 验证→突破封号层级。锻造台等级决定产出品质；变现为内购为主 + 少量广告，付费点是月卡/终身卡（可跳过广告）与折扣礼包。
- **交互形式**：竖屏单指点锻造锤，回合自动战斗「看着打」；跟随主线逐个解锁玩法模块；挂机十分钟收大量资源。
- **界面视觉**：UI 布局与寻道大千同构：中央锻造台 + 底部功能栏；深蓝夜空底（约 #1E2A4A）、魂环金（约 #E8B54A）、昊天锤铜色点缀。
- **角色设计**：斗罗 IP 武魂/魂师形象（开局选武魂，推荐昊天锤）；稀有度用魂环年限外圈表现：白→黄→紫→黑→红。
- **动效**：打铁锤击火花四溅；魂环展开环绕角色的年限光效，「一锤千年、十锤万年」的数值期待感。
- **环境/背景**：星斗大森林等 IP 经典场景做战斗背景；宗门为社交场景。
- **3D 元素**：无，2D。
- **可直接复用**：①开箱动作主题化换皮（打铁/砍树/点灯皆可）；②稀有度用「环绕外圈」直观可视；③IP 梗造传播点（唐三打铁）；④月卡跳广告的混合变现；⑤「开箱→验证→BD」三段循环结构。

## 6. 百炼英雄
- **类型/题材**：佣兵团 like Squad RPG + 开放地图探索，九九互动。
- **玩法循环**：摇杆走位探索→靠近怪物自动战斗、靠近资源自动采集→食物养英雄、木材驱散迷雾建小镇、钻石开训练营天赋→副本/试炼塔/竞技场验证。英雄抽卡 + 升星/守护兽/符文；付费点密集：高品质英雄限时碎片礼包、低价复活。
- **交互形式**：单摇杆手动走位，无自动寻路；BOSS 扇形 AOE 需走位躲避维持专注；20 游戏币复活制造「差一点就能过」的心理；同一时间只给一个主线目标的单线引导。
- **界面视觉**：相比同类暗色末日调，画面更明亮鲜艳：草绿（约 #7BC96F）、天蓝（约 #4AA8E0）；Q 版圆润卡通；血条与伤害数字显著放大。
- **角色设计**：Q 版多英雄小队同屏作战（乌瑟尔、德鲁伊、李白等混搭）；品质神话/传说分色；英雄满级等级深、升星拆碎片。
- **动效**：割草平 A 群伤反馈密集；掉宝弹跳自动拾取；操作手感（移动灵敏度、无碰撞卡顿）是核心卖点。
- **环境/背景**：迷雾覆盖的开放大地图，「消灭怪物→采集→上交→驱迷雾」推进；修复小镇解锁传送阵/招募大厅/训练营等功能建筑。
- **3D 元素**：2.5D 俯视角伪 3D 场景，2D 角色。
- **可直接复用**：①单线引导同一时间只给一个目标；②走位微操 + BOSS 预警圈维持专注；③低价复活钩子；④资源→驱散迷雾的探索节奏；⑤抽到高品质英雄即时弹限时礼包。

## 7. 几何王国
- **类型/题材**：几何风放置卡牌，多元文化角色大杂烩（小红帽、美队、孙悟空同框）。
- **玩法循环**：组建 5 人英雄小队推主线→挂机/离线收益→升级/升星/装备强化/技能升级→副本、竞技场、联盟战验证。付费点为抽卡与限时礼包；另有钓鱼副玩法（渔具分部位升级）。
- **交互形式**：自动战斗为主，高难 BOSS 手动调站位与技能时机；竖屏轻点，响应快；日常任务积分制（500 分领周宝箱）。
- **界面视觉**：扁平高饱和几何色块撞色：红（约 #FF6B6B）、青（约 #4ECDC4）、黄（约 #FFE66D）；分区简洁、无强制氪金弹窗压迫感；底部导航。
- **角色设计**：齐天大圣（神话全能战士）、复仇者（传说后排杀手）等流行梗角色几何化 Q 版；品质分神话/传说等并配专属红武外观。
- **动效**：技能带碰撞机制表现，站位冲撞、击退有物理感；大招穿透后排 + 沉默/眩晕状态图标清晰。
- **环境/背景**：森林、矿山、古堡、冰雪等章节场景，全部由几何图形构成，辨识度统一。
- **3D 元素**：无，2D。
- **可直接复用**：①用圆/三角/方块等基础图形做角色，大幅降美术成本；②1 坦 1 辅 3 输出的站位格策略；③碰撞机制增加策略层；④钓鱼等收集向副玩法；⑤高饱和三色撞色 UI 方案。

## 8. 冒险大作战
- **类型/题材**：史莱姆 like + 开箱子融合的竖版放置 RPG，4399，蘑菇「菇勇者」题材。
- **玩法循环**：上半屏自动战斗→下半屏点「神灯」爆装→新旧装备对比后更换/出售→金币升级神灯提高品质→闯关/竞技场验证。技能与伙伴按白→粉 8 级养成；付费点为钻石、免广告礼包、抽奖；周期性冲榜把日常弱反馈攒成周期强反馈（积攒-释放）。
- **交互形式**：上下分屏并行，最高频操作是点神灯 + 即时二选一（换/卖）；神灯次数耗尽可挂机恢复；16 级解锁自动点灯；技能可延迟释放、有方案切换。
- **界面视觉**：Q 萌冒险岛风，蘑菇红伞（约 #E84A3F）、森林绿（约 #5BA85C）；上半战斗约 45%、下半装备约 55% 的上下分屏。
- **角色设计**：蘑菇主角（3 职业 × 2 分支），换法宝装备实时换装、蘑菇头可换色；5 个上阵伙伴自由搭配；品质 8 阶色（白绿蓝紫黄橙红粉）。
- **动效**：萌系 Q 弹击打音画；PVP 竞技场双方互扔技能、满屏爆炸特效主打热闹。
- **环境/背景**：家园含矿山、科技园、雕像、庄园等属性建筑；材料副本、深渊之门（整点世界 BOSS）多场景。
- **3D 元素**：无，2D。
- **可直接复用**：①上下分屏「战斗 + 开箱」并行布局；②神灯次数 = 体力化开箱限制；③周期冲榜的积攒-释放节奏；④偷菜/抢车位式轻社交降心理门槛；⑤装备新旧属性对比弹窗即时决策。

## 9. 这城有良田
- **类型/题材**：唐代古风模拟经营 + 卡牌僚属 + 后期 SLG（九州玩法），益世界。
- **玩法循环**：开粥棚收流民→修民居增人口→农田/工坊/集市产业链→僚属派驻建筑产资源→政务/趣闻事件→以税收与人口收口推官场主线；后期重心转向九州 SLG。付费点为僚属招募与各类礼包。
- **交互形式**：点空地锤子建建筑、点卷轴接政务、僚属派遣自动执行；建筑有「功能联动」摆放策略（水井近农田缩短灌溉、工坊集中降运输成本）。
- **界面视觉**：水墨古画场景，宣纸米白（约 #F2EBDD）、黛青（约 #3C4A5A）、朱红印章点缀（约 #B03A2E）；白墙青瓦、园林庭院，参考唐代名画。
- **角色设计**：僚属（农吏/账房/校尉等）古风水墨立绘，进入僚属界面有拟老友寒暄的语音；市井小贩、官差等 NPC 各有对白。
- **动效**：建造扬尘、收获飘字、政务卷轴展开；事件以对话气泡 + 选择支呈现。
- **环境/背景**：2.5D 县城全景可逐步扩建；县外州域接差事，九州为 SLG 大地图。
- **3D 元素**：伪 3D 场景 + 2D 立绘。
- **可直接复用**：①僚属 = 卡牌派驻经营建筑的双层绑定；②建筑邻近加成的摆放策略；③随机趣闻事件拉市井烟火气；④前期单机经营 → 后期 SLG 的三步软引导（简化兵种/奖励挂钩/渐进转移重心）；⑤人口 + 税收双指标收口成长。

## 10. 无尽冬日（Whiteout Survival 小游戏版）
- **类型/题材**：冰雪末日生存 SLG + 放置经营 + 英雄卡牌，点点互动/世纪华通。
- **玩法循环**：熔炉供暖保幸存者→分配工作（健康/幸福度管理）→城建产木/肉/煤/铁→英雄 5 人队放置推图→约 90 分钟后开放 4X 大地图，进入联盟、州（State）与 SvS 大战。付费深度极高：VIP、英雄碎片（幸运轮盘）、加速、转服票。
- **交互形式**：点击逐一升级建筑内部件；探险模式全自动；暴风雪倒计时制造紧迫感促回访；Drill Camp 让全队英雄等级同步到前 5 名，大幅降低练新卡的肝度。
- **界面视觉**：等距（isometric）俯视城建，冷蓝白灰主调（约 #DCE9F2 / #7FB3D5）与炉火暖橙（约 #F39C12）强对比；UI 比同类 SLG 明显更干净。
- **角色设计**：写实风英雄立绘头像（Molly、Flint 等），兵种分步/弓/枪，品质分色；英雄对局仅 PVE，与大地图 4X 战斗解耦。
- **动效**：烟囱升烟、落雪天气、部队行军动画；熔炉 Max 模式火焰爆发；风声与凿冰音效强化「冷」的体感。
- **环境/背景**：固定布局基地（不可自由摆放）+ 雪原大地图，中央 Sunfire Castle 为争夺目标；暴风雪事件场景。
- **3D 元素**：3D 场景 + 2D 立绘混合。
- **可直接复用**：①冷蓝 + 暖橙双色调对比塑造题材氛围；②用放置经营做约 90 分钟新手外壳再开 SLG 的平滑过渡；③幸存者情感化照护钩子（会生病、会「死亡」）；④暴风雪倒计时驱动回流；⑤英雄等级同步机制（Drill Camp）降低养成挫败。
