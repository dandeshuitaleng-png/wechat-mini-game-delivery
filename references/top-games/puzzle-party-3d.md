# 解谜 · 棋牌 · 派对 · 3D 类（10 款）

> 色值为目测估计（标「约」），落地时对真机截图取色校准。

## 通用设计公式

1. **免文字教程**：用饱和度差、线条连续性、动态符号做可交互引导，本地化成本归零。
2. **单一符号贯穿**：星星、蛋、画框——一个视觉符号反复出现在 UI/场景/角色上，建立记忆点。
3. **经典玩法+离谱大招**：老玩法（五子棋/找茬）叠加夸张技能特效，爽感压倒合理性，自带短视频传播。
4. **球形/蛋形角色**：动作容错高、挤压拉伸天然萌，皮肤设计成本低。
5. **物理喜感**：软体摇摆、「要倒不倒」的魔性走位，玩家失误也是传播素材。
6. **氛围三件套**：光影、雾气、留白，低多边形也能出高级感。

## 1. 纪念碑谷2
- **类型/题材**：视错觉解谜 / 神圣几何 + 母女成长叙事。
- **玩法循环**：观察建筑结构→旋转/拖动机关制造空间错位→引导角色抵达终点。共 14 章，单关约 5-15 分钟。
- **交互形式**：纯点触+拖拽（旋转把手、滑动模块）；无文字教程，靠降低可交互机关饱和度、动态符号做视觉引导。
- **界面视觉**：极简无 HUD，低多边形（Low Poly）+ 平面渐变；配色大胆撞色——珊瑚橙约 #E8833A 撞深蓝约 #2E3A59，粉绿关卡约 #F4C2C2 / #A8D5BA，底色米白约 #F5EFE6。
- **角色设计**：母亲萝尔+女儿双角色，剪影化小人无五官，靠体型差与动作（晃腿、吹笛）传情。
- **动效**：潘洛斯三角/德罗斯特效应错觉动画、植物见光生长、机关转动阻尼感；通关星光汇聚。
- **环境/背景**：超现实场景（眠海之城、果园），大量留白+渐变光影，每帧可作壁纸。
- **3D 元素**：3D 场景 2.5D 呈现，固定视角，低模无 PBR，性能开销极小。
- **可直接复用**：①用色彩饱和度差做可交互引导，免教程；②固定视角+低多边形，小团队可承受；③错觉机关作为关卡核心噱头；④双角色体型差协作谜题；⑤音效与操作联动（转动声、脚步声差异化）。

## 2. 万宁五子棋
- **类型/题材**：魔改棋牌 / 短视频梗（万宁叔 IP）+ 古风五子棋。
- **玩法循环**：选阵法大招→15×15 棋盘对弈→技能互克翻盘。单局 2-5 分钟，节奏极快。
- **交互形式**：单手点击落子+战前选 1 个阵法（局中不可换），零学习成本。
- **界面视觉**：竖屏棋盘居中，水墨宣纸底约 #F5F0E1，墨色棋子约 #2B2B2B，朱砂点缀约 #C0392B；古风 UI+古筝配乐。
- **角色设计**：无重角色，卖点是「万宁阵法/五雷阵/八卦阵」等中二技能命名与棋盘特效。
- **动效**：技能释放全屏夸张特效（雷劈清屏、棋子裂变、敌子变色），爽感压倒合理性。
- **环境/背景**：棋盘即全部场景，辅以乱斗模式变换地形（旋转棋盘、迷雾森林）。
- **3D 元素**：纯 2D，性能无压力，包体约 46MB。
- **可直接复用**：①「经典玩法+离谱大招」魔改公式，老玩法新传播点；②技能分复制/攻击/防御三类互克，维持平衡；③看广告升技能等级的 IAA 变现闭环；④每周更新阵法/乱斗地形保活跃；⑤梗 IP 联动引流。

## 3. 墨斗
- **类型/题材**：硬核格斗 / 水墨 + 西游英雄。
- **玩法循环**：1v1 实时对战→连招压制→爆气收尾，无数值养成纯靠技术。单局 3 分钟内。
- **交互形式**：四枚大尺寸方向键+A 轻击/B 重击/C 翻滚/D 跳/R 必杀，支持键位自定义；预输入、目押等进阶技巧。
- **界面视觉**：横版对战，手绘水墨；宣纸底约 #F7F3E9，墨黑约 #1A1A1A，朱砂红约 #B03A2E 做血条与点缀；UI 极简突出角色。
- **角色设计**：12 位西游角色（孙悟空、猪八戒、蜘蛛精），保留经典形象+粗笔画描边强化动作可读性；皮肤无数值加成，公平竞技。
- **动效**：打击顿帧、墨色飞溅特效、受身/板边反弹，拳拳到肉接近街机手感。
- **环境/背景**：山水写意场景，留白多、不抢戏，服务对战可读性。
- **3D 元素**：2D 手绘骨骼动画，无 3D。
- **可直接复用**：①粗描边提升小屏角色动作辨识度；②风格化题材（水墨×西游）做格斗差异化；③外观付费不影响平衡的口碑变现；④教学分初级/进阶/连招/自由四层降门槛；⑤小键位布局适配单手。

## 4. 躺平发育（猛鬼宿舍）
- **类型/题材**：多人非对称塔防 / 恐怖宿舍生存。
- **玩法循环**：抢宿舍→躺床产金币→升门/建炮台→抵御猎梦者破门；身份可对调当鬼。单局 5-10 分钟。
- **交互形式**：竖屏点触建造/升级，俯视图一屏看完，零操作门槛；策略在升级优先级（床→门→炮台）。
- **界面视觉**：俯视宿舍格子，暗灰蓝夜色约 #3B4A5A，金币与可升级项亮黄约 #F1C40F 高亮，危险红警示；像素 Q 版降低恐怖感。
- **角色设计**：躺平者/猎梦者双阵营，猛鬼形象夸张滑稽化；角色、坐骑靠碎片解锁（看广告得碎片）。
- **动效**：鬼拍门震屏、门血条抖动、炮台开火频闪；升级瞬间满血的「卡点救命」反馈极强。
- **环境/背景**：宿舍楼俯视剖面，黑暗走廊+门缝光营造压迫感。
- **3D 元素**：2D 俯视，轻量（约 50MB）。
- **可直接复用**：①「躺平产资源」反向塔防钩子，题材自带传播；②非对称双身份模式延长生命周期；③升级即时回血制造心流峰值；④门朝上的 UI 细节（血量不被遮挡）值得抄；⑤碎片+广告解锁身份的 IAA 设计。

## 5. 蛋仔派对
- **类型/题材**：派对闯关 / 潮玩盲盒世界观（蛋仔岛）。
- **玩法循环**：大厅社交→多人竞速/生存闯关→赛季盲盒抽外观→UGC 工坊造图。单局 3-5 分钟。
- **交互形式**：虚拟摇杆+跳跃/扑/抓举三键，滚动变形加速；UGC 地图有简易上手引导。
- **界面视觉**：圆角糖果 UI，蛋仔黄约 #FFC107 主色，粉约 #F48FB1、蓝约 #4FC3F7 辅助；高饱和低明度差，亲子友好。
- **角色设计**：蛋形 Q 体+四肢，黄黑粉蓝四小只性格人设；盲盒赛季外观+至臻染色定制；高频 IP 联动（平均 11 天一次：奥特曼、蜜雪冰城、DongDong 羊），线下潮玩反哺 IP。
- **动效**：滚动变球、扑倒弹跳、淘汰击飞；UGC 图过关礼花与排行榜反馈。
- **环境/背景**：乐园式大厅可互动（摩天轮、钢琴），赛季主题关卡（零食季、马戏团）。
- **3D 元素**：全 3D 卡通渲染（非 PBR），圆润软材质+描边；低端机降帧保流畅。
- **可直接复用**：①蛋形/球形角色方案，动作容错高又萌；②盲盒赛季制外观经济；③地图编辑器 UGC 生态（地图破 1 亿张）；④联动节奏表打法；⑤大厅即社交场景。

## 6. 元梦之星
- **类型/题材**：社交派对 / 超开星乐园（星星世界观）。
- **玩法循环**：乐园大厅互动→竞速/躲猫猫/推理等多模式→时装社交→UGC 家园建造。单局 3-8 分钟。
- **交互形式**：摇杆+跳跃/飞扑，物理引擎驱动「要倒不倒」的魔性走位；大厅道具拾取即互动。
- **界面视觉**：UE4 打造，多巴胺高饱和糖果色——亮粉约 #FF6FA5、天蓝约 #40C4FF、明黄约 #FFEA00；星星元素贯穿全场景（炸弹、大门、箱子）。
- **角色设计**：三头身「星宝」，动物公仔外套+圆润关节，表情丰富强化社交表现；换装+五官自定义。
- **动效**：软体物理摇摆、碰撞弹性、跳跃吊威亚感；躲猫猫变身道具的欺骗性动作。
- **环境/背景**：梦幻乐园广场（跷跷板、海盗船、热气球均可交互），童话光影。
- **3D 元素**：UE4 全 3D，细节表现强于同类；物理模拟是核心卖点，性能投入高。
- **可直接复用**：①「星星」单一符号贯穿全场建立记忆点；②三头身+玩偶服降低时装设计成本；③物理喜感=传播素材；④大厅等待区做成可玩设施；⑤高饱和糖果配色锁定 Z 世代。

## 7. 成语小秀才
- **类型/题材**：文字填字 / 科举晋升 + 轻度养成。
- **玩法循环**：交叉填成语→通关得金币→升官职（童生→状元）、修宅院招门客。单关 1-3 分钟，体力制。
- **交互形式**：点选备选字填入空格，点错再点撤回；卡关用提示卡/免答卡（广告获取）。
- **界面视觉**：竖屏上半题板下半字库；古风宣纸米约 #F5EFE0，黛蓝约 #34495E，朱红印章约 #C0392B，金色官衔约 #D4AC0D；简约护眼。
- **角色设计**：落魄书生逆袭成长线，宅邸/门客/服饰随官职解锁，身份感即皮肤。
- **动效**：填对字弹跳入格、通关卷轴展开、晋升动画仪式感。
- **环境/背景**：宅院场景随等级从破屋到府邸，成长可视化。
- **3D 元素**：纯 2D。
- **可直接复用**：①「答题+科举养成」双层目标拉长留存；②填字交叉验证机制（横竖共用字）；③成语词典后置教育价值；④好友排行+朋友圈求助裂变；⑤体力+广告提示的经典 IAA 结构（疯狂游戏系，与肥鹅同厂）。

## 8. 全民找茬
- **类型/题材**：观察力休闲 / 找不同。
- **玩法循环**：限时对比双图→点出 5-10 处差异→通关领金币/红包。单局 1-3 分钟。
- **交互形式**：单点标记差异，双指拖拽缩放查角落；误点扣时/扣血，提示道具兜底。
- **界面视觉**：上下/左右双图对比布局，UI 极薄；底色柔和白约 #FAFAF5，点缀薄荷绿约 #48C9B0、天蓝约 #5DADE2；图库为高清写实插画。
- **角色设计**：无角色，主题图集即内容（风景、美食、萌宠 20+ 类），头像框/称号做轻收集。
- **动效**：找对圈选打勾、找齐全图彩带；进阶版加飘动/闪烁动态差异与爆破解压特效。
- **环境/背景**：图片即场景，节日限定关卡保更新。
- **3D 元素**：纯 2D 图片流。
- **可直接复用**：①双图同屏+缩放的观察交互范式；②误点惩罚控制乱点；③动态差异（光影/位移）做难度分层；④好友同步 PK 同图比速度；⑤图库周更+红包提现的留存组合拳。

## 9. 画中世界（Gorogoa）
- **类型/题材**：叙事解谜 / 手绘绘本、无文字哲思。（选它而非《花园之间》：画框嵌套机制独创性更高，2D 手绘+四格 UI 更适配小游戏降维改造）
- **玩法循环**：在 2×2 画框中拖拽/缩放/嵌套画面→拼接跨图关联→推动主角一生追寻。全流程约 2 小时，单谜题 2-10 分钟。
- **交互形式**：拖拽移动画框、点按缩放局部、叠放嵌套；零文字提示，靠画面内线条连续性暗示可拼接处。
- **界面视觉**：四格画框即 UI；暖色系手绘——米约 #E8DCC8、淡黄约 #F2E2B6、浅棕约 #A98A5B，关键物用高饱和色引导（红果约 #D64545、蓝兽约 #4A6FA5）；铅笔笔触+晕染质感。
- **角色设计**：主角从少年到老年多形态穿插，沉默苦行僧形象；五色巨兽作符号化 IP。
- **动效**：跨画框物体流转（苹果落地、乌鸦飞起）的无缝拼接动画，「柳暗花明」顿悟时刻。
- **环境/背景**：城市、沙漠、雪山手绘场景，对称/黄金分割构图，宗教曼陀罗意象。
- **3D 元素**：纯 2D 手绘（作者学过 3D 辅助构图），千张画稿扫描。
- **可直接复用**：①画框拖拽/嵌套作为核心机制可小游戏化；②高饱和点缀色做解谜引导；③无文字叙事降本地化成本；④非线性时空穿插提升复玩解读欲；⑤「万物同构」拼接触发连锁动画的爽点设计。

## 10. 肥鹅健身房
- **类型/题材**：合成+模拟经营 / 萌系健身，女性向。
- **玩法循环**：棋盘三合一合成道具→交付任务得星星→解锁装修七大区域→吸引更多肥鹅客人。碎片游玩，离线有收益。
- **交互形式**：拖拽相同物品堆叠合成，点开发射器产出道具；任务列表驱动目标，新手引导 1-2 分钟。
- **界面视觉**：左侧合成棋盘+右侧经营场景双区；治愈奶油色——鹅黄约 #FFD966、薄荷绿约 #A9DFBF、奶白约 #FDFEFE；精致 2D 卡通。
- **角色设计**：原创「肥鹅」形象蠢萌独特，每位客人有人设故事；图鉴收集（棋盘元素/装饰/客人）给道具奖励。
- **动效**：合成升级弹跳光效、肥鹅用器材时汗水横飞的幽默演出；解锁新区前的「未知面纱」悬念。
- **环境/背景**：健身房分区解锁（有氧区/泳池/冥想室），DIY 家装可调位置朝向。
- **3D 元素**：2D 卡通渲染，轻量约 100MB。
- **可直接复用**：①「合成+经营」双循环互喂（首个经营型合成）；②独特动物形象+有趣表演=记忆点；③任务线 5-6 条随机刷新保新鲜；④区域解锁前置未知的探索欲；⑤高信息密度+离线收益适配碎片习惯。

## 附：微信小游戏 3D 化趋势摘要

消除、塔防率先 3D 化（《箭头消消消》为微信首款千万级 Unity 小游戏），SLG/ARPG/MMO 等重度品类借「手改小」跟进。技术上以 Unity WebGL/团结引擎导出为主流，Cocos Creator、LayaAir 原生支持 3D，three.js 用于轻量场景；混元 3D 等 AI 建模进一步压低美术成本。选型详见 `references/external-resources.md`。
